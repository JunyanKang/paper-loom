# 设置详解

[首页](../README.md) · [English](SETTINGS.en.md)

设置中心有四个页面，各阅读场景共用相关选项。

## 阅读与翻译

选择翻译服务与目标语言，配置划选自动朗读、译文显示、译文朗读、图注过滤等阅读行为。内置翻译服务无需个人 API 密钥，但需要联网且受服务可用性影响。

使用模型翻译时，选择大模型服务并点击其左侧齿轮，在下方浮层选择服务商，填写其要求的接口地址、模型和 API 密钥，再运行连接测试。支持预设服务商和自定义兼容接口；模型清单可刷新。服务费用由所选服务商收取，不包含在 Paper Loom 中。

不要将密钥粘贴到反馈截图中。密钥通过 Zotero 登录管理器保存在本机。修改共享翻译配置会同时影响正文和摘要翻译。

## 声音与引擎

![声音与引擎](images/voices-zh.png)

朗读语言默认英语，可切换为普通话、日语或法语。声音按语言、性别与序号命名，例如“美音 · 女1”“英音 · 男1”，便于选择和试听；语速可单独调整。

“离线声音”标题旁显示安装状态，其下是下载／修复与检查图标：向下箭头用于下载，扳手用于修复，盾牌对号用于检查。下载开始后，进度条与取消图标、进度文字在按钮下方展开；中断后可以继续。检查也可取消；成功提示在 5 秒后消失，失败时会提示修复声音。已有引擎通过上方“声音位置”的文件夹按钮导入。声音包无需随每次插件升级重新下载。

## 快捷键

在「快捷键」页点击操作对应的键位并录入新的组合键；避免与 Zotero 或系统快捷键冲突。默认键位以该页当前显示为准，点击回转箭头图标可恢复默认配置。

## 外观

![外观](images/appearance-zh.png)

10 张主题卡片固定展开，点击预览图切换。下方另有 4 个全局背景预设和 1 个自定义图片位置：点击空卡片导入 PNG、JPG 或 WebP，图片居中填充各窗口，卡片同步显示缩略图；再次点击该卡片删除图片。点击原有主题卡片可恢复对应的背景。

透明度、界面语言和角色互动位于主题下方。角色动作图标依次预览 8 组动作；自动互动可关闭，也可调整间隔，系统的减少动态效果设置同样有效。字幕与摘要共用的字体和字号在「阅读与翻译」页设置。

更新设置、指南、隐私和反馈位于此页底部，可调整检查周期、自动更新或手动检查新版本。
