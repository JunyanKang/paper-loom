## 外观与界面语言

主题预览固定展开，按浅到深排列。下方有四个全局背景和一个自定义位置：点击空卡片导入 PNG、JPG 或 WebP，图片在主窗口中固定于右下角；再次点击缩略图删除。

设置、文献列表和作者网络共用同一背景画布，右下角保持固定，切换窗口不重新缩放图片。

透明度滑块调整窗口表面。界面支持中文、英文、日文、法文和德文；切换语言不会更改论文原文或翻译目标。小书互动默认开启，间隔一分钟，并尊重系统的减少动态效果设置。

## 快捷键

表格左右两列集中显示十个动作。点击键位后按新的组合键，再次点击可取消录入。回转箭头恢复默认；自定义时避开系统和 Zotero 已占用的组合。

## 翻译与引用

选择服务商图标，设置译文字体、字号、位置与引文格式。字体同时用于正文译文和摘要译文。Cell、Nature、Science 位于引文格式列表前列，其余按名称排序。

选择大模型翻译后，点击旁边的齿轮，在浮层填写服务商、接口、模型和密钥，再测试连接。模型清单可以刷新。服务商可能收费，费用不包含在插件中。

## E-utilities 与声音

NCBI API key 可选。填好后点击连接图标测试，连接成功变绿；修改密钥后清除旧的成功状态。

**发音环境**一行用扳手安装或修复声音，盾牌检查声音。缺失或需要修复时扳手为红色；正常时恢复常规颜色、盾牌变绿。检查成功文字五秒后消失，失败提示会保留。展开进度时，操作按钮留在原位。

语速、阅读模式、重读次数、语种和声音位于阅读控件中，见[使用指南](GUIDE.md)。

## 页面底部

**更新、指南、隐私、反馈**四个入口固定在底部。更新由你手动检查和安装。设置和文献列表保持相同高度，较小窗口可滚动查看内容。
