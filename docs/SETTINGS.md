# 设置详解

[首页](../README.md) · [English](SETTINGS.en.md)

设置中心有四个页面，各阅读场景共用相关选项。

## 阅读与翻译

选择翻译服务与目标语言，配置划选自动朗读、译文显示、译文朗读、图注过滤等阅读行为。内置翻译服务无需个人 API 密钥，但需要联网且受服务可用性影响。

使用模型翻译时，选择服务商，填写其要求的接口地址、模型和 API 密钥，再运行连接测试。支持预设服务商和自定义兼容接口；模型清单可刷新。服务费用由所选服务商收取，不包含在 Paper Loom 中。

不要将密钥粘贴到反馈截图中。密钥通过 Zotero 登录管理器保存在本机。修改共享翻译配置会同时影响正文和摘要翻译。

## 外观

选择主题、字体、字号、透明度和背景图片，或跟随系统语言。字幕与摘要共用阅读字体和字号；界面语言与翻译目标语言可分别选择。角色互动可关闭，也可调整间隔；系统的减少动态效果设置同样有效。

## 声音与引擎

![声音与引擎](images/voices-zh.png)

选择文本语言及其音色，调整语速并试听。英语可选择美音/英音，普通话和日语提供多种男女声音色，法语提供 Siwis。语种自动识别对极短文本和混合语言可能不准确，可手动指定。

下方可以下载匹配当前电脑的引擎、取消或继续下载、检查声音、查看安装位置。已有引擎通过文件夹按钮导入。声音包无需随每次插件升级重新下载。

## 快捷键与更新

在「快捷键」页点击操作对应的键位并录入新的组合键；避免与 Zotero 或系统快捷键冲突。默认键位以该页当前显示为准，可恢复默认配置。

设置底部可检查更新，选择周期检查频率，并打开帮助、隐私和反馈。定期检查用于发现新版本，自动安装由 Zotero 的更新选项控制。
