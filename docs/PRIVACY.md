<h1 align="center">隐私与数据</h1>

<p align="center"><a href="../README.md">首页</a> · <a href="PRIVACY.en.md">English</a></p>

听读在本机完成，翻译和资料查询按功能连接外部服务。Paper Loom 无需注册账号，不添加遥测或使用统计。

## 哪些内容会联网

| 场景 | 数据如何处理 |
| --- | --- |
| PDF 听读 | 文本在本机提取和合成；安装声音后无需向语音服务上传文本 |
| 翻译与模型连接测试 | 将待翻译文字或测试文本发送给所选翻译/模型服务商 |
| 文献与作者信息 | 打开相关界面时可能自动补充当前文献资料，将 DOI、题名、作者或其他书目查询字段发送到相应公开服务 |
| 基础作者网络 | 从本地文献条目计算；身份补充和在线资料查询会访问公开服务 |
| ORCID 履历 | 将所选 ORCID 发送到 ORCID 公共接口，返回公开资料并本地缓存 |
| 期刊指标 | 可读取本地兼容指标数据，或下载公开指标包；显示来源与年份，以来源为准 |
| 插件、声音、模型清单更新 | 从 GitHub / GitHub Pages 下载资源；服务器可看到常规请求信息，如 IP 地址 |

翻译服务包括腾讯、微软、Google 或你选择的模型服务商。公开资料查询使用 Crossref、PubMed/PMC、Europe PMC、Semantic Scholar、ORCID 等相应来源；第三方处理方式受其自身隐私政策约束。Paper Loom 不自动向这些服务上传整篇 PDF。使用译文功能时，请确认所选服务适合处理当前文本。

## 本地保存什么

- Zotero 数据目录下的 `paper-loom`：稍后读、书目缓存、作者网络索引、公开履历缓存、外观设置及背景图片等。
- Zotero 应用数据目录下的 `paper-loom`：声音下载缓存和安装后的引擎。
- Zotero 配置：阅读进度、快捷键、声音选择、翻译设置。
- Zotero 登录管理器：模型服务 API 密钥，以 `Paper Loom API` 标识保存，不写入声音包。

这些记录独立于 Zotero 文献条目，不会全部随 Zotero 同步迁移。更换电脑前，请备份 Zotero 数据与配置；声音包可在新电脑上重新安装。

## 离线使用

不使用在线翻译和在线资料界面时，可离线听读；在完全离线环境中，资料补充会不可用或使用已有缓存。若需要阻止所有插件网络活动，请停用插件或通过系统网络策略控制。

## 卸载与清理

卸载插件会保留声音包和本地记录，方便以后恢复使用。如果也要清理这些文件：

1. 先在模型设置中移除 API 密钥，并备份需要保留的数据。
2. 退出 Zotero，只删除上述 **paper-loom 子目录**。保留 Zotero 数据目录、文献附件与其他插件文件。
3. 在 Zotero 设置编辑器中清理 `extensions.paperLoom.voice.*` 和 `extensions.zotero.paperLoom.shared.*` 偏好。

## 反馈

分享截图或日志前移除密钥、私人全文和个人信息。问题反馈入口：[GitHub Issues](https://github.com/JunyanKang/paper-loom/issues)。

## 科研助手（1.2）

发送消息会将问题、必要的会话历史、论文元数据和检索到的相关原文片段提交给单独配置的模型。在设置中确认模型支持图片后，助手可按需请求并发送相关页面图。文献检索默认可用，使用时检索词会发送给 Europe PMC、Crossref 或已配置的 Brave；读取网页会访问相应公开学术网站。模型服务商依据其政策处理内容。

对话及引用记录保存在 Zotero 数据目录的 `paper-loom/assistant/`，不会自动随 Zotero 同步。助手和搜索密钥单独保存在 Zotero 登录管理器的 `Paper Loom Assistant API` 域中，与翻译密钥隔离。模型不能自行改写或删除文献库；在引用卡中点击保存或稍后读仍由用户触发。

日历索引还保存每天的提问次数和最后一次提问的短摘要，用于本地日期筛选和搜索。
