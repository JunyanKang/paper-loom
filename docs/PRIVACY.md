# 隐私与数据

[首页](../README.md) · [English](PRIVACY.en.md)

Paper Loom 无需账号，不添加遥测或使用统计。部分功能使用外部服务，具体如下。

| 场景 | 数据如何处理 |
| --- | --- |
| PDF 听读 | 文本在本机提取和合成；安装声音后无需向语音服务上传文本 |
| 翻译与模型连接测试 | 将待翻译文字或测试文本发送给所选翻译/模型服务商 |
| 文献与作者信息 | 打开相关界面时可能自动补充当前文献资料，将 DOI、题名、作者或其他书目查询字段发送到相应公开服务 |
| 基础作者网络 | 从本地文献条目计算；身份补充和在线资料查询会访问公开服务 |
| ORCID 履历 | 将所选 ORCID 发送到 ORCID 公共接口，返回公开资料并本地缓存 |
| 期刊指标 | 可读取本地兼容指标数据，或下载公开指标包；显示来源与年份，以来源为准 |
| 插件、声音、模型清单更新 | 从 GitHub / GitHub Pages 下载资源；服务器可看到常规请求信息，如 IP 地址 |

翻译服务包括腾讯、微软、Google 或你选择的模型服务商。公开资料查询使用 Crossref、OpenAlex、Semantic Scholar、ORCID 等相应来源；第三方处理方式受其自身隐私政策约束。Paper Loom 不自动向这些服务上传整篇 PDF。使用译文功能时，请确认所选服务适合处理当前文本。

## 本地保存什么

- Zotero 数据目录下的 `paper-loom`：稍后读、书目缓存、作者网络索引、公开履历缓存、外观设置及背景图片等。
- Zotero 应用数据目录下的 `paper-loom`：声音下载缓存和安装后的引擎。声音设置中的「声音文件位置」可查看当前引擎路径。
- Zotero 配置：阅读进度、快捷键、声音选择、翻译设置和更新偏好。
- Zotero 登录管理器：模型服务 API 密钥，以 `Paper Loom API` 标识保存，不写入声音包。

这些插件记录不等同于 Zotero 条目，也不承诺随 Zotero 同步自动同步到其他电脑。迁移电脑时，先备份 Zotero 数据与配置；新电脑可重新下载匹配平台的声音。

## 关闭联网与清理

不使用在线翻译和在线资料界面时，可离线听读；在完全离线环境中，资料补充会不可用或使用已有缓存。若需要阻止所有插件网络活动，请停用插件或通过系统网络策略控制。

卸载插件不主动删除声音或本地记录。完整清理前先备份，然后退出 Zotero，只删除上述 **paper-loom 子目录**，不要删除 Zotero 数据目录本身。通过 Zotero 设置编辑器清理 `extensions.paperLoom.voice.*` 和 `extensions.zotero.paperLoom.shared.*` 偏好；API 密钥可先在插件模型设置中移除。不要删除其他插件或文献附件。
