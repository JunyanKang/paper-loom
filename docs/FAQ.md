# 常见问题

[首页](../README.md) · [English](FAQ.en.md)

## 没看到小书

确认插件已启用且 Zotero 版本满足要求。文献库入口位于左侧工具按钮区；也可使用「工具 → Paper Loom」。PDF 内悬浮小书应自动出现在右下方；切换回 PDF 或重新打开附件后再检查。报告问题时附上 Zotero 版本与截图。

## 下载中断或很慢

插件和声音文件由 GitHub 提供，网络速度因环境而异。保留已完成分片后重试即可，不必手动安装其他程序。确认磁盘空间充足、没有代理或防火墙阻止 GitHub 下载。

## 声音装好了却没有声音

先点「检查当前声音」，再试听；检查系统输出设备、音量和蓝牙连接。首次启动引擎可能需要稍等。若提示目录不可用，重新导入正确引擎文件夹或使用修复下载。

## 中文、日文或英文读错了

短句和混合语言可能影响自动识别。手动指定语种和音色；对于专业缩写或公式，语音合成不一定等同于人工发音。14 种声音都是本地合成声音，不是真人录音。

## 扫描 PDF、表格或双栏顺序不对

先确认 PDF 能选中文字；扫描件需 OCR。复杂布局可能导致提取顺序不正确，可改用划选、单句或段落模式。分享复现样本时请使用可公开的 PDF。

## 引文没识别出来，或没有摘要

PDF 的编码、排版或引用格式会影响识别。打开引文面板，尝试通过 DOI 或标题确认文献。元数据源不一定提供摘要；不完整字段不会自动补成虚构内容。

## 翻译失败

检查网络、目标语言与所选服务。内置服务可能限流，可稍后重试或换服务。模型接口需正确的地址、模型和密钥，并可能产生服务商费用；使用连接测试确认配置。

## 作者网络很少，或者同名作者混淆

基础网络来自当前 Zotero 文献库，而不是互联网全部论文。补全作者、年份和 DOI 有助于匹配。通过论文与 ORCID 核对身份，不要仅凭同名自动合并不同研究者。

## 去哪里反馈

在 [GitHub Issues](https://github.com/JunyanKang/paper-loom/issues) 提供 Paper Loom/Zotero 版本、系统和架构、操作步骤与预期结果。截图与日志请去除 API 密钥和私人文献内容。
