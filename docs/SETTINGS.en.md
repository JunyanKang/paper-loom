# Settings

[Home](../README.en.md) · [简体中文](SETTINGS.md)

The settings center has four pages. Related options apply across reading views.

## Reading & translation

Choose a provider and target language, and configure automatic selection reading, translation display, spoken translation, caption filtering, and related behavior. Built-in translation services do not require your own API key, but need connectivity and depend on service availability.

For model translation, choose the LLM service and click the gear beside its logo. In the floating editor, choose a provider, enter its endpoint, model, and API key, then test the connection. Preset providers and compatible custom endpoints are supported; model lists can be refreshed. Provider charges are separate from Paper Loom.

Do not include keys in feedback screenshots. Keys are stored locally using Zotero’s login manager. Shared translation settings affect both PDF passages and abstracts.

## Voices & engine

![Voices & engine](images/voices-en.png)

Reading defaults to English; Mandarin, Japanese, and French are also available. Each voice has a flag and a distinct portrait: the flag identifies its region or accent, and the portrait distinguishes the speaker. Choose a voice, preview it with the headphones button, and adjust its speed.

Installation status appears beside “Speech environment”, with action icons immediately below: a down arrow to download, a wrench to repair, and a checked shield to test voices. Progress, an icon-only cancel button, and status text expand underneath without moving the action buttons. Interrupted downloads can resume. Voice checks can also be cancelled. A success message clears after five seconds; a failed check keeps a repair prompt visible. Import an existing engine using the Voice folder button above. Unchanged voice packages need not be downloaded for every plugin update.

## Shortcuts

On **Shortcuts**, select an action’s shortcut and record a new key combination. Avoid conflicts with Zotero or the operating system. The page shows the current defaults and provides a circular-arrow button to restore defaults.

## Appearance

![Appearance](images/appearance-en.png)

All 10 theme cards stay visible, ordered from light to dark. Click a preview to select it. The row below offers four global backgrounds and one custom-image slot. Click the empty slot to import a PNG, JPG, or WebP. The image fills each window from its centre and appears in the slot as a thumbnail; click the slot again to remove it. Selecting an original theme card restores its background.

Transparency, interface language, and companion interactions sit below the cards. The motion icon cycles through eight performances. Automatic interactions can be disabled or timed, and reduced-motion preferences are respected. Shared caption and abstract font settings are on **Reading & translation**.

Update settings, help, privacy, and feedback are at the bottom of this page. Choose a check interval, enable automatic updates, or check for a new version manually.
