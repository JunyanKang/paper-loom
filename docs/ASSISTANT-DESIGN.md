## 使用路径

划选译文、朗读控制栏和主面板底部使用同一个「对话气泡」图标。主面板增加独立助手页，与朋友圈、文献列表、设置并列。划选入口固定携带原文、译文、页码与范围；朗读入口固定携带当前句/段与译文；主入口关联当前 PDF。打开入口不会自动发送论文。

对话页沿用现有窗口尺寸、主题和底部导航。上方是历史、新对话与收起；中间是消息与可回到原文的来源；底部默认保留输入框、格式入口与发送/停止。根据 PDF、划选和文献库入口自动判断当前论文或多篇研究，不显示手动范围控件。入口上下文自动带入，文献检索默认可用；图片工具仍受模型能力设置约束。助手页编辑期间固定展开，关闭或切换页后保留草稿与历史。

## 科研行为约定

助手区分原文结果、作者解释、推断与待验证假设。分析实验设计时检查对照、重复单位、混杂因素与证据边界；不虚构 DOI、页码、联网结果或看过的图。检索所得摘要不等于全文阅读。论文、网页、图中文字都是证据材料，不是指令。文献来源以引用标号和页码标识呈现。悬停检索所得的文献标号，打开现有完整文献条目卡：摘要、摘要翻译、入库状态、保存、稍后读与引文复制共用原有模块；不为在线结果伪造当前 PDF 中的引用位置。来源记录随对话保存，未知引用标号保持纯文本。

内置起始任务：解释选中内容、梳理论文贡献、审视证据与局限、提出后续实验、查找相关研究。用户的自然语言问题优先，模板仅填入输入框。

## 技术设计

- 前端：原生 Zotero HTML/CSS，独立助手模块，复用主题与页面切换；消息用安全 DOM 渲染，不执行模型 HTML。
- 后端：插件内控制器直接调用用户配置的模型，无额外服务器、Python 或常驻进程。支持 OpenAI 兼容接口和 Anthropic Messages。
- 配置：独立 `paperLoom.assistant.*` 首选项和 `Paper Loom Assistant API` 登录存储域；不读取、继承或改写翻译密钥。供应商预设仅复用公开地址列表，模型名可编辑；总设置中的科研助手入口复用翻译模型的浮层、服务商图标与四个操作按钮，附加搜索配置；支持模型列表刷新、连通测试、清除密钥。视觉能力由用户按实际模型开启。
- 流式：增量解析 SSE，节流绘制；支持取消、错误提示与重试。工具调用串行且有限轮数；同一时刻只运行一个请求，避免重复计费与抢占。
- 文献上下文：使用当前附件和父条目元数据；PDF 按页异步提取，全文按段分块，本地检索相关片段，附页码。输入预算明确限制，未纳入的内容不声称已读；用户可使用读页工具补充。
- 图片：用户主动附加当前 PDF 页，缩放到受限分辨率，再通过已开启视觉能力的模型发送；不后台上传整本 PDF。模型也可在用户打开看图权限后请求指定页。
- 联网：默认提供 Europe PMC / Crossref 实时文献检索及受支持学术网站的公开 HTTPS 网页读取。通用网页搜索通过可选 Brave Search API；其密钥另存。无搜索配置时仍可检索文献，明确不声称已搜索整个互联网。
- Zotero：读取本地条目、当前文献及固定范围内的索引文本、批注与笔记。用户可以预览回答并将其保存为指定文献的子笔记；写库、改注释、删除文献不作为模型工具开放。
- 工具约束：固定工具白名单、参数校验、超时、响应大小、最大结果数、最大调用次数。拒绝私有地址、凭据 URL 和重定向的网页请求；模型与工具响应不写入调试日志。

## 会话与资源

会话按 UUID 分文件写入 Zotero 数据目录 `paper-loom/assistant/`，索引保存标题、日期、论文标识，以及本地日期下的提问次数和末次提问摘要（最多 160 字符）。时区改变后重建日期索引。原子写入、串行保存；损坏文件保留以便恢复，不静默覆盖。日历按提问次数分五档着色；跨天会话按各天实际活动归档。日期与搜索状态在返回时保留。历史搜索、改名、删除、Markdown 导出在本机完成。改名和删除在记录下方展开，操作栏位置固定。密钥从不进入会话、导出或提示词。

每个打开的助手视图保留当前会话与有限草稿；默认仅挂载最近 16 条消息，较早消息按需展开。完成消息复用 DOM，流式内容按批追加；编辑区不实时解析 Markdown，预览由用户触发。PDF 文本缓存最多两个附件、5 分钟，阅读器采用弱引用；逐页提取时让出事件循环，有页面/字符预算；切换、取消、卸载清理请求、定时器和事件。对话是本地存储，不随 Zotero 条目同步；迁移需用户自行备份数据目录。删除会话删除对应文件，不能从索引重新恢复。

## 验收

覆盖三个入口、配置隔离、流式文字与工具、取消、超时、错误、重试、会话重载/删除/导出、上下文截断、恶意材料、图像能力限制、默认联网与图片能力限制及中英文界面。用隔离 Zotero 实例核验真实 PDF 上下文和 UI；网络工具用公开样例实测。用户模型未配置时只验证受控协议，不把模拟回复称作真实模型验证。

## 当前验证边界

科研助手自 1.2.0 起提供。协议与工具调用通过本机受控服务验证；真实供应商的模型质量、计费、工具调用及视觉能力取决于用户所选模型，不能由协议测试代替。页面图支持 PDF 文本以外的视觉上下文，但不等于模型已正确理解科研图。

多篇研究、证据边界、笔记保存与后续实施顺序见 [研究工作流设计](ASSISTANT-ROADMAP.md)。

## 论文内引用与表达

完成的回答按前一条用户消息保存的上下文解析论文内引用，而不是跟随当前打开的 PDF。支持数字括号、英文 ref.、中文引用编号和作者年份；相邻编号与作者年份共同核对。多篇书目对同一编号有不同解释时保留纯文本，已知页码及检索来源仍使用原链接。复用参考文献缓存，异步更新已挂载的消息节点；不为解析引用自动打开其他附件。保存精简引用记录以便历史恢复，排除 PDF 几何与字符数据。代码和已有链接不再次解析。

织知先给出科学解释，把不确定性放在对应结论旁；复杂问题按内容组织，小问题直接回答。必要的证据边界仍保留，避免将内部工具预算、检查清单或重复免责声明变成回答的主体。

## 富文本与图片

Markdown 经 DOM 逐项渲染，支持强调、列表、引用、表格、代码和公开 HTTPS 链接；HTML 保持纯文本，远程图片保持外链。来源详情延迟构建，标题行固定，外部来源在前，本地页码按论文分组。页码范围只在每个来源都已知时转为链接。

图像用会话 UUID 下的独立 PNG 文件保存，缩略图最长边 160，正文图片最长边 1600，原始输入上限 8 MB。对话 JSON 只保存媒体标识，放大时再读大图；关闭预览释放节点，删除对话移除图片目录。每会话最多 12 张。导出 Markdown 和保存 Zotero 笔记目前只包含文字与来源，图片需单独下载。

文字生图由独立按钮主动发起，一次一张；不作为模型可自行调用的工具。使用助手服务商的 OpenAI 兼容 Images 接口，模型名称单独配置，接收有大小上限的 base64 栅格输出。协议由受控本地服务验收，真实供应商质量与速度需逐个模型验证。
