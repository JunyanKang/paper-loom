# 作者网络与学术履历

[首页](../README.md) · [English](NETWORK.en.md)

## 从文献库建立朋友圈

点击小书 →「朋友圈与学术履历」。网络根据本地 Zotero 条目的作者信息和共同论文建立；文献库越完整，能看到的关系越丰富。首次打开需要读取条目并计算布局，之后可复用已有结果。

![作者网络](images/network-zh.png)

搜索作者或论文，点击节点查看关联内容；聚焦作者可查看其合作者与共同论文。拖动画布、缩放或使用全景按钮调整视野。详情中的论文可打开、复制引用或刷新信息；离开详情后可返回原来的视野。

姓名相同不一定是同一人。网络反映的是当前文献库中的署名和共同论文，不代表完整合作史，也不适合直接用作学术评价。扩展查询需要联网时会通过相应在线操作执行。

## 查看公开履历

使用作者详情中的履历入口或输入有效 ORCID，打开公开资料。时间线展示资料中存在的教育、任职与作品，可筛选类别、查看来源并打开相关论文。

![公开履历](images/career-zh.png)

图中为 Dawang Zhou 的公开 ORCID（0000-0002-9053-5249）。ORCID 内容由资料维护者提供，可能有遗漏或日期不全；请核对姓名、单位和来源。网络节点与姓名搜索结果都不能单独证明身份。

履历在网络中打开，关闭后回到原来的作者与视野。已查询的公开资料会本地缓存，以减少重复等待；联网刷新可取得新的公开内容。
