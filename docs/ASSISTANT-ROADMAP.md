<h1 align="center">织知 · 从阅读到研究</h1>

织知的核心工作流是：确定研究对象，提出问题，核查来源，把有用的结论留在对应文献旁。它沿用 Paper Loom 的阅读界面，尽量减少在聊天、论文和笔记之间来回寻找的成本。

## 研究对象先于回答

一个会话有一个明确的研究范围。当前论文适合解释段落、阅读图表和追问方法；选中文献适合比较证据和整理批注。从 PDF 或划选入口自动使用当前论文，从文献库入口自动使用选中文献。新对话会重新识别，旧会话保存在历史中；临时切换 Zotero 的选中条目不会改变已固定的范围。

目前支持最多八篇所选文献。多篇模式首先提供元数据和摘要，模型根据问题请求索引文本、批注或笔记。不会为了打开对话批量打开 PDF、构建全库向量索引，或把全部附件上传给服务商。

## 可追溯的证据

| 证据 | 使用方式 | 显示与边界 |
|---|---|---|
| 元数据与摘要 | 快速认识研究问题、筛选文献 | 复用文献条目与摘要翻译卡，不称作阅读全文 |
| PDF 页文字 | 查阅已打开论文的具体页面 | 引用可回到原 PDF 页，区分不同文献的同页码 |
| Zotero 全文索引 | 对所选论文按问题提取片段 | 无可靠页坐标时不伪造页码，点击来源回到条目 |
| 批注 | 查看原文摘录及用户评论 | 保留两类内容，引用可回到批注所在页面 |
| 子笔记 | 整理用户已有的理解和问题 | 明确为用户笔记，不当作论文原始结果 |
| 页面图 | 结合图注、坐标轴与实验设计看图 | 沿用视觉能力开关；需已打开相应 PDF |
| 在线文献 | 查找当前范围之外的相关研究 | 沿用实时检索与文献卡，保留来源和访问边界 |

同一来源跨轮复用标识，不同 PDF 的第一页不再共用同一个引用。已删除或不在范围内的条目不能被任意 ID 读取。缺少全文、索引或视觉能力时返回明确缺口，不能把未读取当作没有相关证据。

## 界面与操作

会话界面不显示范围按钮和篇数栏，由入口与文献选择自动确定上下文。来源与回答操作共用一行；笔记预览隐藏重复的助手标题，给正文留出空间。聊天主体、历史日历、输入框和底部导航延续既有主题和尺寸。多篇模式提供「比较文献」「整理批注」起始问题；这些按钮只填入问题，由用户发送。

完整回答的操作栏增加笔记图标。点击后在同一面板预览回答和来源，选择本次范围内的目标文献，再点击保存。保存生成新的 Zotero 子笔记，不覆盖旧笔记；重复点击或从历史再次保存同一回答不会产生重复副本。保存后可定位到笔记。模型没有写库工具。

本轮不加入自动改标签、移动收藏夹、覆盖批注或删除条目的行为。这些操作需要可查看的变更清单、撤销路径和单独的权限设计。

## 模块边界与资源策略

| 层 | 当前职责 |
|---|---|
| `context.js` | 捕获阅读入口、受限 PDF 提取、缓存及 Zotero 变更失效 |
| `zotero.js` | 范围校验、文献与子项读取、笔记持久化边界 |
| `tools.js` | 工具白名单、来源身份、检索结果与错误处理 |
| `controller.js` | 固定每轮上下文、请求预算、停止、消息保存 |
| `research-ui.js` | 预览、用户确认保存；不承担模型请求 |
| `history.js` / `store.js` | 会话恢复、日历检索、持久化及已有记录兼容 |

每轮保留原有五轮工具预算、最多十次工具调用和单个活动请求。每次所选文献全文读取最多 1 MiB 索引，返回最多 12,000 字符片段；笔记最多八条，每条 1,600 字符；批注最多二十四条。条目与文件变化清空 PDF 缓存，卸载时注销监听。多篇模式不自动进行完整 PDF 提取；划选问题也不先扫描整篇再丢弃片段。

读取使用 Zotero 现有索引，没有新增常驻服务。当前索引检索仍是关键词排序，尚未实现语义检索、全文缺页补取、跨设备会话同步或整库增量知识图谱。

## 下一阶段的落地顺序

1. **收藏夹范围与证据清单。** 用可见的条目选择器分页处理大集合，显示可读附件、缺失全文和已检索状态。先验证二十篇、百篇集合的响应时间和内存，再增加范围上限。
2. **逐页证据定位。** 将索引命中关联到 PDF 页码与原文矩形；实现前保留当前“不提供推断页码”的规则。验收以真实 PDF 的跨页段落、双栏文字和图注定位为准。
3. **图表研究。** 让用户选择图或图页，并把图、图注、相关方法和结果一起交给模型；先验证图号与页面号不会混淆，再加入跨论文图表比较。
4. **研究产物。** 在现有预览保存基础上增加证据表、实验计划和阅读清单模板。所有写入继续由用户确认；批量操作需要预览范围、失败重试和撤销。
5. **模型质量验收。** 对真实供应商分别测试短问答、多文献矛盾证据、缺失全文、图表单位、嵌套实验设计和提示注入。记录证据支持程度与错误类型；协议正确不等于科学结论正确。

## 验证方式

单元测试覆盖范围权限、来源冲突、取消、写入权限、HTML 转义和重复保存。隔离 Zotero 测试覆盖真实论文、受控比较条目、批注、笔记、历史恢复和保存路径；中英文截图与几何检查确认长标题和小尺寸窗口不挤出控件。

本轮受控回答仅检验工具与界面闭环，不作为真实模型科研质量验收。测试详情记录于本地构建目录，发布和个人库安装另行执行。

## 连接回答与论文书目

回答中提到论文内部参考文献时，使用该条消息的论文上下文查找书目；编号与作者年份相互核对后复用完整文献卡。已识别记录随会话保留，历史重开不依赖当前 PDF。首次匹配依赖已打开论文的书目，未打开附件和存在歧义的条目不猜测链接。后续可扩展对未打开 PDF 的索引书目读取，但不能因此引入后台批量扫描。
