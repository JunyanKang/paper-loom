# 使用指南

[首页](../README.md) · [English](GUIDE.en.md)

## 打开与收起

点击文献库左侧工具栏或 PDF 中的小书，直接打开设置。底部的作者、文献、齿轮图标切换朋友圈、引文与稍后读和设置。点击窗口外或再次点击小书可收起窗口；拖动小书可调整位置。

每篇文档一次展开一个主窗口。设置、文献列表与朋友圈直接切换，底部导航保持固定，不会中断朗读；不同 PDF 标签页与独立阅读窗口各自保留状态。

## 选择阅读范围

| 模式 | 使用方法 |
| --- | --- |
| 划选 | 拖选 PDF 中的文字，松开后按当前设置开始听读 |
| 单句 | 选中句内任意文字，听取完整句子；可重复当前句 |
| 段落 | 选中段内文字，听取完整段落；可设置循环次数 |
| 全文 | 从文首、所选位置或保存的进度开始连读 |

悬停译文，下方出现两行控制按钮：第一行是句子与段落导航、暂停／继续、停止；第二行是四种朗读模式和一个当前语种国旗，当前模式带有背景色。悬停国旗向上展开语言列表，当前语种也保留在列表中。开启译文朗读时，悬停列表中的国旗，左侧会展开该语言支持的声音；小头像叠在国旗右下角，与设置中的声音选择同步。单击当前国旗开关译文朗读，双击开关译文显示。暂停保留位置，停止结束任务。模式、循环次数（1、2、3、5、10、∞）、全文起点、语速和声音均在「设置 → 声音与引擎」中调整。悬浮小书点击打开设置，悬停不再展开快捷栏。

悬停句子或段落重读按钮，选择 1、3、5 或 ∞ 次；两种循环图标分别控制当前整句和整段，默认一次。鼠标进入译文或控件区域后，朗读完当前整句自动暂停；移出后自动继续。手动暂停不会因移出而恢复。离开控件区域约 0.7 秒后按钮收起，期间移回即可继续操作。文献卡片或摘要窗口与译文重叠时，译文和控件会淡出；遮挡解除后恢复。

PDF 需要有可提取的文本。扫描件请先 OCR；复杂表格、公式和特殊排版可能无法按预期朗读。正文过滤会处理引文标记与页眉页脚；图注是否参与朗读可自行选择。

## 对照翻译

语种选择使用国旗，翻译服务与大模型服务商使用 Logo；服务商图标支持悬停查看名称。配置 LLM 后，其图标变为所选服务商的 Logo。设置页的四个分类图标分别打开阅读与翻译、声音、快捷键和外观；更新选项位于外观页底部。选择大模型服务后，点击其左侧齿轮配置服务商和模型。

译文显示默认开启。悬停译文下方的语言图标可直接选择目标语言；单击当前语言图标开启或关闭「朗读译文」。双击切换译文显示，开启时显示浅色背景，关闭时去掉选中背景，图标始终保留。开启译文朗读后，语言列表只保留支持语音的语言；关闭后恢复全部翻译语言。划词翻译卡片中的国旗与译文控制栏联动，切换后刷新译文；三个范围图标对应单句、划选和段落，悬停耳麦按钮后，会出现四个等宽模式区域；点击单句、划选、段落或全文图标即可开始朗读一次，全文从所选位置开始。翻译目标语言不等同于界面语言。网络翻译需联网，内置服务可能限流，也可使用自己的模型服务。

## 查看正文引文

在支持的数字或作者年份引文上悬停，查看对应参考文献；可定位正文引用位置、打开本地文献或 DOI、复制格式化引用。识别效果取决于 PDF 文本结构；无法识别时可打开引文面板手动查看，或通过 DOI/标题查找。

点击或悬停论文标题可展开摘要。摘要支持翻译、原文对照与听读。若本地没有摘要，可按界面提示查询在线元数据；来源未提供摘要时，Paper Loom 不会编造内容。

![引文摘要](images/references-zh.png)

## 稍后读与保存

把感兴趣的文献加入「稍后读」，之后可直接从文献库入口回到清单，无需先打开 PDF。可从清单打开文献、查看摘要、复制引用或保存到 Zotero。保存前检查标题、作者、年份与 DOI；信息相近的候选文献不一定是同一篇。

从稍后读移除一个条目，不等于删除 Zotero 中的论文。查找全文时仍受出版商访问权限限制；Paper Loom 不绕过付费或登录限制。
