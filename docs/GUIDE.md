## 打开一篇论文

鼠标移到小书上即可展开控制面板，首次打开进入设置，之后回到上次使用的面板。底部三个图标依次进入作者网络、文献列表和设置。移出小书与面板区域后短延迟收起，跨过中间间隙或重新移入时保持展开；也可按 Esc 收起。拖动小书可以调整位置。切换主窗口不打断正在播放的声音。

## 决定读多少

划选文字后点击耳麦开始。悬停耳麦可直接选择四个模式，默认段落模式、读一次；划选本身不会触发朗读。

| 模式 | 阅读范围 |
| --- | --- |
| 单句 | 所选位置所在的句子 |
| 划选 | 选中的文字 |
| 段落 | 所选位置所在的段落 |
| 全文 | 从所选位置或阅读进度继续连读 |

声音开始后，启动弹窗和用于启动的选区收起。准备声音期间新建的其他选区会保留。

## 在原文旁控制播放

<p align="center">
  <a href="images/caption-controls-zh.png"><img src="images/caption-controls-zh.png" alt="听读控制栏" width="493"></a>
</p>

把鼠标移到正在读的原文、译文或其下方，出现两行按钮。上行控制句子、段落、暂停和停止；下行切换模式、语速、语种与译文显示。

- 悬停重读图标，选择 **1、3、5 或 ∞** 次，句子与段落分别控制。
- 悬停倍率，选择 **0.5×、0.75×、1×、1.25×、1.5× 或 2×**，新倍率用于后续合成。
- 鼠标停留在阅读区域时，读完当前句暂停；移开自动继续。手动暂停后，需要自己继续。
- 移出约 **180 毫秒**后收起控件；及时移回可继续操作。

引文、摘要或新划选弹窗遮挡朗读译文时，译文暂时淡出，遮挡解除后恢复。关闭译文显示后，控件仍可在正在读的原文下方出现。

## 切换语言与声音

当前国旗代表目标语种。点击国旗开关译文朗读，眼睛按钮开关译文显示；双击国旗也可切换显示。展开语言列表选择新语种，正文、划词和摘要翻译会一起更新。

译文朗读开启时，菜单显示可发音的语种，国旗右下角的小头像代表声音。英语分美音和英音，悬停可选择其他音色。不支持发音的译文语种仍可翻译，但不会提供可用的译文声音。

原文声音和译文声音的偏好分别保留。界面语言只改变按钮与说明，不等同于翻译目标语种。

## 跟进一条引文

<p align="center">
  <a href="images/references-zh.png"><img src="images/references-zh.png" alt="文献信息和摘要" width="876"></a>
</p>

悬停正文中可识别的数字或作者年份引文，打开文献卡片。可定位引用、打开本地附件或 DOI、复制格式化引用。标题下的摘要支持原文、译文和双语，不提供朗读入口。

将值得追读的论文加入 **稍后读**，之后从文献列表进入，不必重新打开原 PDF。保存到 Zotero 前核对标题、作者、年份和 DOI。移出稍后读不会删除已有 Zotero 条目。

## 遇到特殊 PDF

扫描件需先做 OCR。多栏、公式、表格和异常编码可能影响阅读顺序或识别。可以缩小到划选范围，或从文献列表手动查找。全文获取仍取决于你的出版商与机构访问权限。

## 和科研助手讨论（1.2）

从划选译文或朗读控件的对话图标进入，带入当时的原文、译文与页码；从主面板助手页进入，关联当前论文。先在总设置中配置助手模型。打开助手不会发送内容，点击发送后才会提交问题、相关论文片段及需要的历史。

可继续追问、停止生成、查看历史、改名、删除或导出 Markdown。文献检索默认可用；在总设置中确认模型支持图片后，助手可按问题需要请求 PDF 页面图。回答中的页码回到 PDF；悬停文献标号打开熟悉的文献条目窗口，继续看摘要、译文、入库或加入稍后读。历史中的引用信息仍然保留。

对话记录按日历浏览，左右箭头分别切换年份和月份，中间显示选中的完整日期，点击回到今天。日期底色越深，当天提问越多；跨天对话会出现在每个有提问的日期。选中日期查看记录，打开后可返回原日期。搜索同时匹配标题、关联论文和每天最后一次提问的摘要。重命名、删除确认及导出反馈都保留在对应记录内。
