# 使用指南

[首页](../README.md) · [English](GUIDE.en.md)

## 打开与收起

点击文献库左侧工具栏或 PDF 右下角的小书，直接打开听读主窗口。底部的作者、耳麦、文献、齿轮图标分别进入朋友圈、听读、引文与稍后读和设置；悬停图标可查看名称。四个主窗口均使用这组图标切换，当前功能以主题色轮廓和图标标出；页面内只保留当前功能的操作。点击页面外的 Zotero 或 PDF 区域、再次点击小书，或按 Esc 收起窗口。悬停小书可使用听读快捷控制，拖动可调整位置。

同一文档一次展开一个主要面板：听读、引文、朋友圈或设置。切换面板会直接过渡到目标页面，不会停止朗读；再次打开引文或朋友圈可继续查看原来的位置。各个主面板共用右下角位置，展开与收起都连接到小书。不同 PDF 和独立阅读窗口各自保留面板状态。弹出的详情或编辑窗口位于当前面板上方，关闭后返回原面板。

## 选择阅读范围

| 模式 | 使用方法 |
| --- | --- |
| 划选 | 拖选 PDF 中的文字，松开后按当前设置开始听读 |
| 单句 | 选中句内任意文字，听取完整句子；可重复当前句 |
| 段落 | 选中段内文字，听取完整段落；可设置循环次数 |
| 全文 | 从文首、所选位置或保存的进度开始连读 |

悬停小书显示快捷栏，再悬停最左侧的模式图标可展开一列四个图标，直接选择朗读模式；悬停各图标可查看名称。暂停／继续共用一个主按钮。显示译文时，悬停译文可在其下方使用一行句段导航、暂停、停止、四个朗读模式和当前国旗；当前模式以背景色标出。悬停国旗向上展开其他语种，单击开关译文朗读，双击开关译文显示。没有显示译文时，悬停暂停按钮仍可展开横排导航。暂停保留当前位置，停止结束当前任务。语速、重复次数和音色在面板与声音设置中调整；循环可选 1、2、3、5、10 或 ∞（持续循环）。划选自动朗读可在设置中关闭。

PDF 需要有可提取的文本。扫描件请先 OCR；复杂表格、公式和特殊排版可能无法按预期朗读。正文过滤会处理引文标记与页眉页脚；图注是否参与朗读可自行选择。

## 对照翻译

语种选择使用国旗，翻译服务与大模型服务商使用 Logo；服务商图标支持悬停查看名称。配置 LLM 后，其图标变为所选服务商的 Logo。设置页的四个分类图标分别打开阅读与翻译、声音、快捷键和外观；更新选项位于外观页底部。选择大模型服务后，点击其左侧齿轮配置服务商和模型。

译文显示默认开启。悬停快捷栏的语言图标可直接选择目标语言；单击当前语言图标开启或关闭「朗读译文」。双击切换译文显示，开启时显示浅色背景，关闭时去掉选中背景，图标始终保留。开启译文朗读后，语言列表只保留支持语音的语言；关闭后恢复全部翻译语言。划词翻译卡片中的国旗与快捷栏联动，切换后刷新译文；三个范围图标对应单句、划选和段落，悬停耳麦按钮后，会出现四个等宽模式区域；点击单句、划选、段落或全文图标即可开始朗读一次，全文从所选位置开始。翻译目标语言不等同于界面语言。网络翻译需联网，内置服务可能限流，也可使用自己的模型服务。

## 查看正文引文

在支持的数字或作者年份引文上悬停，查看对应参考文献；可定位正文引用位置、打开本地文献或 DOI、复制格式化引用。识别效果取决于 PDF 文本结构；无法识别时可打开引文面板手动查看，或通过 DOI/标题查找。

点击或悬停论文标题可展开摘要。摘要支持翻译、原文对照与听读。若本地没有摘要，可按界面提示查询在线元数据；来源未提供摘要时，Paper Loom 不会编造内容。

![引文摘要](images/references-zh.png)

## 稍后读与保存

把感兴趣的文献加入「稍后读」，之后可直接从文献库入口回到清单，无需先打开 PDF。可从清单打开文献、查看摘要、复制引用或保存到 Zotero。保存前检查标题、作者、年份与 DOI；信息相近的候选文献不一定是同一篇。

从稍后读移除一个条目，不等于删除 Zotero 中的论文。查找全文时仍受出版商访问权限限制；Paper Loom 不绕过付费或登录限制。
