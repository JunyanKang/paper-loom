## 打开一篇论文

鼠标移到小书上即可展开控制面板，首次打开进入设置，之后回到上次使用的面板。底部导航可进入作者网络、文献列表、科研助手和设置。移出小书与面板区域后短延迟收起，跨过中间间隙或重新移入时保持展开；也可按 Esc 收起。拖动小书可以调整位置。切换主窗口不打断正在播放的声音。

## 决定读多少

划选文字后点击耳麦开始。悬停耳麦可直接选择四个模式，默认段落模式、读一次；划选本身不会触发朗读。

| 模式 | 阅读范围 |
| --- | --- |
| 单句 | 所选位置所在的句子 |
| 划选 | 选中的文字 |
| 段落 | 所选位置所在的段落 |
| 全文 | 从所选位置或阅读进度继续连读 |

声音开始后，启动弹窗和用于启动的选区收起。准备声音期间新建的其他选区会保留。

## 在原文旁控制播放

<p align="center">
  <a href="images/caption-controls-zh.png"><img src="images/caption-controls-zh.png" alt="听读控制栏" width="493"></a>
</p>

把鼠标移到正在读的原文、译文或其下方，出现两行按钮。上行控制句子、段落、暂停和停止；下行切换模式、语速、语种与译文显示。

- 悬停重读图标，选择 **1、3、5 或 ∞** 次，句子与段落分别控制。
- 悬停倍率，选择 **0.5×、0.75×、1×、1.25×、1.5× 或 2×**，新倍率用于后续合成。
- 鼠标停留在阅读区域时，读完当前句暂停；移开自动继续。手动暂停后，需要自己继续。
- 移出约 **180 毫秒**后收起控件；及时移回可继续操作。

引文、摘要或新划选弹窗遮挡朗读译文时，译文暂时淡出，遮挡解除后恢复。关闭译文显示后，控件仍可在正在读的原文下方出现。

## 切换语言与声音

当前国旗代表目标语种。点击国旗开关译文朗读，眼睛按钮开关译文显示；双击国旗也可切换显示。展开语言列表选择新语种，正文、划词和摘要翻译会一起更新。

译文朗读开启时，菜单显示可发音的语种，国旗右下角的小头像代表声音。英语分美音和英音，悬停可选择其他音色。不支持发音的译文语种仍可翻译，但不会提供可用的译文声音。

原文声音和译文声音的偏好分别保留。界面语言只改变按钮与说明，不等同于翻译目标语种。

## 跟进一条引文

  <a href="images/references-zh.png"><img src="images/references-zh.png" alt="文献信息和摘要" width="876"></a>
</p>

悬停正文中可识别的数字或作者年份引文，打开文献卡片。可定位引用、打开本地附件或 DOI、复制格式化引用。标题下的摘要支持原文、译文和双语，不提供朗读入口。

将值得追读的论文加入 **稍后读**，之后从文献列表进入，不必重新打开原 PDF。保存到 Zotero 前核对标题、作者、年份和 DOI。移出稍后读不会删除已有 Zotero 条目。

## 遇到特殊 PDF

扫描件需先做 OCR。多栏、公式、表格和异常编码可能影响阅读顺序或识别。可以缩小到划选范围，或从文献列表手动查找。全文获取仍取决于你的出版商与机构访问权限。

## 和科研助手讨论

### 带着问题进入

从划选译文或朗读控件的对话图标进入，带入当时的原文、译文与页码；从主面板助手页进入，关联当前论文。先在总设置中配置助手模型。打开助手不会发送内容，点击发送后才会提交问题、相关论文片段及需要的历史。

### 顺着来源继续读

可继续追问、停止生成、查看历史、改名、删除或导出 Markdown。文献检索默认可用；在总设置中确认模型支持图片后，助手可按问题需要请求 PDF 页面图。回答中的页码回到 PDF；悬停文献标号打开熟悉的文献条目窗口，继续看摘要、译文、入库或加入稍后读。历史中的引用信息仍然保留。

论文中的参考文献也可以直接追读。例如回答里出现「引用 28，Muhar et al. 2018」时，助手会用当前论文的书目核对编号、作者和年份；对应明确后，悬停即可打开同一套文献卡。多篇论文的编号重复、作者年份不符或书目暂不可读时，文字会保持原样，不会随意链接。首次识别需要原 PDF 已打开；识别成功的引用会随对话保存，之后可从历史继续查看。

### 按日期找回对话

对话记录按日历浏览，左右箭头分别切换年份和月份，中间显示选中的完整日期，点击回到今天。日期底色越深，当天提问越多；跨天对话会出现在每个有提问的日期。选中日期查看记录，打开后可返回原日期。搜索同时匹配标题、关联论文和每天最后一次提问的摘要。重命名、删除确认及导出反馈都保留在对应记录内。

### 比较文献与保存笔记

助手自动判断研究对象：从 PDF、划选译文或朗读控件进入时使用当前论文；从文献库进入时使用选中的 1–8 篇文献。选中多篇时提供比较文献的起始问题，无需手动切换范围。比较文献时可按需读取索引文本；整理批注时区分摘录、评论和笔记。没有可用全文时会保留缺口，不把摘要当成全文。

回答旁的笔记图标可打开预览；选择目标文献后保存为子笔记。来源随笔记保留，重复保存同一回答不会重复创建。已有对话保留原研究对象；点击「新对话」后重新识别，原会话仍可从历史恢复。

从 PDF 里提问「比较这些论文」时，如果文献库已选中包含当前论文的多篇文献，新对话也会使用这些论文。超过八篇时请缩小选择；已有会话的研究对象保持不变，需要换一组论文时点击「新对话」。

问题与回复各有圆角边框，来源和操作留在回复下方。需要并排阅读较宽的表格时，可在总设置的「科研助手」一行把对话调到 2× 或 3× 宽。

### 更轻松地整理对话

输入框右侧的 **Aa** 展开格式栏，可插入粗体、斜体、列表、引用和代码，再点眼睛预览。也可直接输入 Markdown；Ctrl/Cmd+B、Ctrl/Cmd+I 为选中文字添加格式。按 Enter 发送，Shift+Enter 换行，中文输入法确认候选词不会发送。问题与回复使用略有区别的主题底色。

“查看来源”展开后保持原位。外部文献排在前面；本文来源合并为一组页码，点击回到原文。多篇论文仍分开，页码不会混在一起。

格式栏的图片按钮可选择 PNG、JPEG 或 WebP，也可粘贴图片。每次附一张、不超过 8 MB；发送前会缩小到最长边 1,600 像素。模型须开启看图能力。发送后图片以缩略图留在历史中，点击放大，再点下载保存。

若需要文字生图，在总设置 → 科研助手模型中填写“生图”模型名称。它使用该助手服务商的密钥与 OpenAI 兼容 `/images/generations` 接口；普通聊天模型和 Anthropic Messages 不会自动获得此能力。输入描述后点星光按钮生成一张示意图，服务商可能计费。当前支持返回 base64 图片的接口；不自动下载模型回复里的远程图片。每段对话最多保留 12 张图片。AI 示意图适合讨论构想，不能作为实验结果。

导出 Markdown 和保存 Zotero 笔记目前保留文字与来源；图片可单独下载。

等待回复时，读取文献与检索进度显示在该条回复框里。灰色小字记录简短步骤；答案完成后自动折叠为“处理过程”，点击可回看。这是实际操作摘要，不是模型隐藏推理的逐字转录。文字、表格和图片都保留在各自的消息框内。
